当题目要求输入一大行数字的时候，此时我们可以用for循环加输入的方法把数字搞进去例如：
  for (int i = 0; i < 10; i++) {
            apples[i] = sc.nextInt();
        }

字符串的时候再用nextLine方法


做题的时候需要增加数字的因果变量可以一起放在if语句，搭配for循环比如：
for (int i = 0; i < 10; i++) {
            if (apples[i] <= height + 30) {
                count++;
            }
        }
